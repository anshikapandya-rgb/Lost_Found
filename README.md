# 🔎 FindIt – Lost & Found Website

**FindIt** is a community-based Lost & Found website designed to help people report lost belongings, discover found items, and reconnect people with their missing belongings.

Our goal is to make finding lost items easier, faster, and more organized through a simple and user-friendly platform.

## 🌟 Features

- 🏠 **Home Page:** Overview of lost and found reports.
- 🔍 **Browse Items:** Search and filter items by name, category, type, and location.
- 📝 **Report an Item:** Submit details of lost or found belongings.
- 📸 **Upload Images:** Add item photos to reports.
- 📊 **Dashboard:** Manage your reported items.
- 🤝 **Contact / Claim:** Submit a claim request for an item.
- 🔄 **Mark as Returned:** Update an item's status when it is returned.
- 📥 **Export Data:** Export reports in JSON format.
- 🔐 **Privacy Tips:** Reminders to protect sensitive personal information.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage API

## 💻 How to Run the Project

1. Clone this repository:

   ```bash
   https://github.com/anshikapandya-rgb/Lost_Found.git
   ```

2. Open the project folder.

3. Open `index.html` in your web browser.

4. Start exploring the FindIt website!

## ⚙️ Current Project Limitations

- Reports are stored in the browser's Local Storage.
- Data is not shared between different users or devices.
- Real user authentication is not implemented.
- Claim requests are currently demo-only and do not send messages.

## 🎯 Project Objective

The main objective of FindIt is to create a simple digital platform where people can report lost and found items and make the process of returning belongings more convenient.
